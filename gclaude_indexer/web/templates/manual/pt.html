1. O que é e para que serve

O GClaude Indexer lê uma pasta cheia de documentos (PDFs, Word, planilhas, e-mails, imagens escaneadas…) e monta, no seu computador, um índice organizado de tudo o que existe nela: qual é cada peça, de que data, de quem, em que página está. Esse índice é feito para ser usado com o Claude.

Ele resolve cinco problemas:

  1. Economia da sua assinatura do Claude. Em vez de enviar o acervo inteiro para o Claude ler (o que consome muito do seu limite de uso), você entrega só o índice. O Claude consulta o índice, descobre exatamente qual documento e qual página interessam, e abre só aquilo.
  2. Acervos muito maiores do que o Claude aguenta. O Claude tem um limite de quanto texto consegue considerar de uma vez. Um índice compacto, dividido por grupo, cabe nesse limite mesmo quando o acervo tem milhares de páginas.
  3. Sigilo. Todo o trabalho pesado (leitura, reconhecimento de texto, classificação) acontece nesta máquina. Nenhum documento é enviado para a internet durante o processamento. A base fica numa pasta sua — e, se essa pasta estiver no Google Drive, você a usa de qualquer computador.
  4. Atualização incremental. Quando você acrescenta, altera ou remove documentos, o sistema refaz só o que mudou, não o acervo inteiro.
  5. Uso pessoal ou corporativo. Funciona para uma pessoa só ou para uma equipe que compartilha a mesma pasta no Drive ou num servidor de arquivos.

2. Começo rápido em 6 passos

  1. Novo projeto. Clique em + Novo projeto, dê um nome, escolha a Pasta de origem (onde estão seus documentos) e confira a Pasta de saída sugerida. O resto pode ficar como está. Clique em Criar projeto.
  2. Rodar tudo. Na tela Execução, clique em Rodar tudo até a classificação. Pode deixar a janela aberta e fazer outra coisa: o progresso aparece sozinho.
  3. Gerar os relatórios. Quando a classificação terminar, clique em Importar e gerar relatórios.
  4. Conferir. A tela Resultado mostra a qualidade, as pendências e uma prévia de cada arquivo gerado.
  5. Baixar o pacote. Em Pacote para um Claude Project novo, clique em Baixar pacote (.zip).
  6. Levar para o Claude. Em claude.ai, crie um Project, cole o conteúdo de project_instructions.md nas instruções e envie os outros arquivos como conhecimento do projeto. Veja os detalhes em Usando com o Claude.

Dica: em cada tela, o botão Ajuda no topo abre um resumo daquela tela, e o ícone ? ao lado de cada campo explica o campo.

3. Tela Projetos

Lista todos os projetos que este computador conhece. Cada projeto vive inteiro na sua pasta de saída (o arquivo project.db dentro dela guarda tudo).

  • Situação: não iniciado (nada lido ainda), em processamento (alguma etapa rodando), classificação pendente (ainda há trechos por classificar) ou o número de peças já prontas.
  • Abrir: vai para a tela Execução do projeto.
  • Excluir: tira o projeto da lista. Você escolhe entre só remover da lista (os arquivos ficam no disco) ou apagar também os arquivos gerados. Nesse caso o sistema apaga só o que ele mesmo criou (banco, cópias convertidas, relatórios). Arquivos seus que estiverem na pasta de saída são mantidos, e a pasta só some se ficar vazia. A pasta de origem nunca é tocada.
  • Abrir projeto existente: para um projeto que não está na lista (reinstalação, computador novo, pasta recebida de outra pessoa). Basta apontar a pasta de saída.
  • Catálogo compartilhado: veja Outro computador e uso em equipe.

4. Novo projeto: cada campo

Na maioria dos casos você só precisa preencher Nome e Pasta de origem. Os outros campos já vêm com valores que funcionam bem.

Identificação

Nome do projeto
Só para você reconhecer o projeto na lista. Não muda nenhum arquivo.
Tema do acervo
Uma ou duas frases sobre o conteúdo (ex.: "processo de licitação da obra X"). Entra nas instruções geradas para o Claude e ajuda a classificação a entender o contexto.

Pastas

Pasta de origem
Onde estão os documentos originais. Nunca é alterada: o sistema só lê.
Pasta de saída
Onde tudo é gravado. O padrão é a pasta de origem com _indexado no final. Pode ficar no Google Drive ou num servidor de arquivos para ser usada em outros computadores.

Acervo

Tipo de acervo
processo numera por folha (f. 1, f. 2…), como um processo administrativo ou judicial; a numeração continua de um volume para o outro. biblioteca numera por página (p. 1, p. 2…), como livros e relatórios.
Como agrupar
Um "agrupador" é um conjunto de arquivos que formam uma unidade (um processo com vários volumes, por exemplo). por subpasta usa o nome da primeira subpasta — o mais comum; por padrão no nome agrupa pelo começo do nome do arquivo, usando o campo seguinte; tudo junto trata a pasta inteira como um único grupo.
Padrão do agrupador
Só para por padrão no nome. É uma expressão regular. Exemplo: ^(\d{4}-\d+) junta "2024-001 - petição.pdf" e "2024-001 - despacho.pdf" no grupo "2024-001".
Extensões incluídas
Quais tipos de arquivo entram. Marque TODOS para aceitar qualquer formato de texto ou documento (executáveis e compactados nunca entram).

Fatiamento, janelas e OCR

Uma janela é um trecho de páginas seguidas que o classificador lê de uma vez para descobrir onde começa e termina cada peça.

Páginas por bloco (80)
PDFs maiores que isso são cortados em partes antes de processar, para não travar em arquivos enormes.
Páginas por janela (16)
Janelas menores erram menos quando há muitos documentos curtos misturados, mas levam mais tempo. Janelas maiores são mais rápidas, mas podem juntar duas peças numa só.
Sobreposição (2)
Quantas páginas do fim de uma janela se repetem no começo da próxima, para não cortar uma peça ao meio. Tem que ser menor que Páginas por janela.
Caracteres por página (2000)
Limite de texto de cada página enviado ao classificador. Evita que uma página com uma tabela gigante ocupe a janela toda.
Idioma do OCR
Idioma usado para reconhecer o texto de páginas escaneadas: por (português), eng (inglês) ou por+eng para os dois no mesmo acervo.

Classificação

Motor de classificação
Quem identifica as peças. Veja a comparação completa em Motores de classificação.
Modelo local
Qual modelo do Ollama o motor local usa. automático usa o padrão (qwen3.5:4b). Escolher outro serve para comparar qualidade.
Processamento
Se o motor local usa a placa de vídeo (GPU). automático e forçar GPU usam o máximo dela — bem mais rápido. somente CPU/RAM deixa a placa livre para outros programas, mas é mais lento.
Paralelismo
Quantos arquivos a conversão e a leitura processam ao mesmo tempo. econômico: um por vez; automático: usa os núcleos do processador e deixa um livre para você continuar usando o computador (recomendado); máximo: termina antes, mas o computador fica lento enquanto isso.
Revisar confiança baixa
Roda primeiro o motor de regras (instantâneo) em tudo e manda para o motor escolhido só os trechos em que as regras ficaram em dúvida. Economiza tempo quando o acervo tem muitos documentos padronizados.

Instruções do projeto

Instruções que você já usa
Se o seu Project no Claude já tem instruções, cole-as aqui. Elas ficam no topo do arquivo de instruções gerado e nunca são apagadas. Veja Suas instruções são preservadas.
Papel nas instruções
Substitui o parágrafo padrão que diz ao Claude qual é o papel dele neste acervo (ex.: "você é um assistente jurídico…"). Em branco, usa o texto padrão.
Regras extras
Regras específicas do acervo, acrescentadas no fim das instruções (ex.: "cite sempre o número do processo", um glossário de siglas).

6. Tela Execução: as etapas

O processamento segue sempre esta ordem. Cada etapa pode ser interrompida e retomada: pausar, fechar o programa ou até desligar o computador no meio não estraga nada — ao rodar de novo, ele continua de onde parou.

  • 1. Varredura — encontra os arquivos da pasta de origem e identifica cópias repetidas (um documento idêntico a outro entra só uma vez).
  • 2–3. Conversão, OCR e fatiamento — transforma cada arquivo em texto. Páginas escaneadas passam pelo reconhecimento de texto (OCR); PDFs enormes são cortados em blocos. É a etapa mais demorada em acervos escaneados.
  • 4. Extração por página — guarda o texto de cada página com sua numeração (f. N ou p. N).
  • 5. Preparação de janelas — divide as páginas em trechos para a classificação.
  • 6. Classificação — o motor escolhido identifica cada peça: tipo, data, autor, resumo e intervalo de páginas.
  • Rodar etapa seguinte: executa só a próxima etapa. Útil para acompanhar passo a passo.
  • Rodar tudo até a classificação: encadeia todas. É o que você vai usar quase sempre.
  • Pausar: para o que está rodando. Para continuar, rode de novo.
  • Importar e gerar relatórios: depois da classificação, junta as peças e grava os arquivos para o Claude.
  • Log ao vivo: conta o que está acontecendo, em linguagem simples. O filtro mostra só avisos ou só erros; copiar copia o log para mandar a alguém.
  • Recursos da máquina: uso de processador, memória e placa de vídeo em tempo real.
  • Motor Claude Code: aparece uma caixa com a frase para dizer ao Claude Code (processe as janelas). Abra o Claude Code na pasta de saída, diga a frase e, quando ele terminar, clique em Reverificar.

7. Tela Resultado: o que é gerado

Todos os arquivos ficam na pasta de saída:

index.md
O sumário: lista os grupos e diz qual arquivo de índice abrir para cada um.
index-<grupo>.md
Um índice por grupo: cada peça com folhas, tipo, data, autor, arquivo e página dentro do PDF, e um resumo.
timeline.md
A cronologia: as peças com data, em ordem.
review.md
A conferência: o que foi lido, o que falhou, lacunas de numeração e documentos removidos.
project_instructions.md
As instruções para o Claude: como usar o índice e a regra de sempre confirmar valores no documento original.
  • Qualidade da classificação: uma pontuação baseada na confiança que o próprio motor declarou e em quantos campos ele preencheu. Não é uma medida de acerto real — confira por amostragem.
  • Pendências: trechos ainda não classificados, folhas sem peça e arquivos que falharam. Resolva antes de considerar o acervo pronto.
  • Pacote para um Claude Project novo: um .zip com todos os arquivos e um guia passo a passo.
  • Liberar espaço: apaga as cópias convertidas e os blocos (pastas converted/ e blocks/). Faça só com os relatórios prontos: numa atualização futura, documentos que precisarem ser relidos passarão de novo pelo OCR.

8. Usando com o Claude

No claude.ai (Projects)

  1. Crie um Project novo (ou abra o deste acervo).
  2. Cole o conteúdo inteiro de project_instructions.md no campo de instruções do Project.
  3. Envie como conhecimento do projeto: index.md, os index-<grupo>.md, timeline.md e review.md.
  4. Quando precisar do conteúdo exato de uma peça, envie à conversa só o documento original indicado pelo índice — é aí que está a economia.

No Claude Code

Abra o Claude Code na pasta de saída (ou numa pasta que tenha acesso a ela e à pasta de origem). O Claude lê o index.md, escolhe o índice do grupo e abre só os arquivos originais necessários, na página indicada.

Por que isso economiza: o índice de um acervo de milhares de páginas costuma ter uma fração mínima do tamanho do texto completo. O Claude gasta sua cota lendo o índice e uma ou duas peças, não o acervo todo.

9. Suas instruções são preservadas

O texto que o GClaude Indexer escreve em project_instructions.md e no CLAUDE.md da pasta de saída fica entre duas marcas invisíveis (GCLAUDE-INDEXER:BEGIN e GCLAUDE-INDEXER:END).

  • Tudo o que estiver fora das marcas é seu e nunca é apagado, nem nas atualizações.
  • A cada nova geração, só o trecho entre as marcas é refeito.
  • Se a pasta de saída já tinha um CLAUDE.md seu, ele é mantido e o bloco do sistema é acrescentado. Uma cópia do original é guardada como CLAUDE.md.bak na primeira vez.
  • Instruções que você já usa no Project podem ser coladas no campo Instruções que você já usa ao criar o projeto: elas vão para o topo do arquivo.

10. Atualizar o acervo

Quando a pasta de origem muda, a tela Execução mostra um aviso com quantos documentos são novos, alterados ou removidos. Clique em Atualizar para ver o plano antes de confirmar.

  • Novos: são lidos e classificados.
  • Alterados: são lidos de novo (com OCR, se necessário) e reclassificados.
  • Removidos: as páginas e peças saem do índice, a cópia convertida é apagada e o nome fica registrado em review.md. Se havia uma cópia idêntica do documento na pasta, ela passa a ser indexada no lugar dele.
  • Mudança de numeração: num acervo do tipo processo, a numeração de folhas é contínua dentro do grupo. Se um documento entra ou sai do meio, as folhas dos documentos seguintes mudam de número. O plano mostra quais são, e o log avisa. Conversas antigas que citavam essas folhas podem ficar desatualizadas.
  • Só os trechos afetados são reclassificados; o resto é aproveitado.

Depois de atualizar, rode Rodar tudo até a classificação e Importar e gerar relatórios, e reenvie os arquivos ao Project do Claude.

11. Outro computador e uso em equipe

  • Pasta de saída no Google Drive (ou num servidor de arquivos): o projeto pode ser aberto de qualquer computador que tenha acesso a ela.
  • Catálogo compartilhado: na tela Projetos, aponte uma pasta dentro do Drive para guardar a lista de projetos. Todos os computadores com o mesmo Drive passam a ver os mesmos projetos.
  • Trava de uso: só um computador por vez trabalha num projeto. Se outro estiver usando, o sistema avisa quem é. A trava expira sozinha depois de um tempo sem uso.
  • Regra de ouro ao trocar de computador: feche o programa no primeiro, espere o Google Drive terminar de sincronizar e só então abra no segundo.

12. Temas e layouts

No topo de qualquer tela há duas escolhas independentes:

  • Tema (as cores): Claro, Escuro, Sépia, Alto contraste e os temas novos com mais movimento.
  • Layout (a forma: fontes, espaçamentos, cantos): Padrão, Técnico, Editorial e Compacto.

Qualquer combinação funciona. A escolha fica salva neste navegador. Se o sistema operacional pedir menos movimento (configuração de acessibilidade do Windows), as animações são reduzidas automaticamente.

14. Problemas comuns

"Projeto em uso em outra máquina"
Feche o programa no outro computador. Se ele travou ou desligou, espere a trava expirar ou escolha Assumir mesmo assim — só se tiver certeza de que o outro não está usando.
"Sinal de sincronização incompleta"
O Google Drive ainda não terminou de baixar o projeto. Espere o ícone do Drive indicar que terminou.
O motor local caiu para "regras"
O Ollama não está rodando ou falta memória. Abra o Ollama e rode a classificação de novo; a tela Sobre mostra o diagnóstico da instalação.
Arquivos com falha em Pendências
Em geral são arquivos protegidos por senha ou corrompidos. Abra-os, salve uma cópia sem proteção na pasta de origem e atualize o acervo.
Lacunas de folhas
Folhas sem peça classificada. Rode a classificação de novo nesses trechos ou confira se o PDF tem páginas em branco.
Aparece "Pedido recusado"
Algum site tentou enviar um comando ao programa e foi bloqueado. Use sempre o atalho do GClaude Indexer ou o endereço http://127.0.0.1:8000.

15. Privacidade e segurança

  • Os documentos são lidos e classificados só neste computador. O motor local conversa apenas com o Ollama desta máquina, nunca por proxy ou internet.
  • O programa só aceita comandos das próprias telas: um site aberto no navegador não consegue mandar ordens a ele.
  • A pasta de origem nunca é modificada.
  • O banco do projeto guarda o texto das páginas. Se o acervo tiver dados pessoais (LGPD), proteja a pasta de saída como protegeria os próprios documentos — inclusive no Google Drive.
  • Ao usar o motor Claude Code ou enviar arquivos ao Claude, aí sim o conteúdo enviado passa pela sua conta do Claude, nas condições do seu plano.
