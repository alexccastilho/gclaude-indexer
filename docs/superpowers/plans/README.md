# Planning documents

These are the implementation plans written before each development phase,
kept as a record of *why* the code looks the way it does. They are
historical documents: each one describes the state of the project at the
moment it was written, and none of them is edited afterwards to match
later changes.

Two consequences of that are worth stating up front, so a reader does not
mistake them for broken links:

- **They are written in Brazilian Portuguese.** The project's own
  documentation moved to English in Phase 14; these predate that move, or
  describe it from the inside.

- **They refer to `ESPECIFICACAO.md`, which no longer exists under that
  name.** Phase 14 (Task 14) translated the specification into English and
  renamed it to [`docs/SPECIFICATION.md`](../../SPECIFICATION.md). Section
  numbers cited in these plans still line up with it. Likewise, module and
  test file names quoted here (`projeto.py`, `tests/test_fase1.py`,
  `estilo.css`, …) are the pre-Phase-14 Portuguese ones; the same files
  live under their English names today (`project.py`,
  `tests/test_phase1.py`, `style.css`).

The user-facing history of what actually shipped is in
[`CHANGELOG.md`](../../../CHANGELOG.md), not here.
